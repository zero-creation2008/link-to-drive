Paste a shared Google Drive file or folder link to copy it into My Drive → Drive Link Imports.

- Optional names with original Drive names detected automatically.
- Folder scanning followed by percentage progress and copied file counts.
- Android imports continue with a foreground notification.
- Windows x64, macOS Intel, and macOS Apple Silicon desktop builds.

On desktop, choose Connect Google. To connect Android, choose Pair phone in the desktop app and open the exported file in the Android app. The Android app encrypts its saved connection using Android Keystore. Delete the exported connection file after pairing.

The macOS apps and Windows executable are unsigned. macOS may require opening the app through Privacy & Security. Windows uses the Microsoft Edge WebView2 runtime.

Google Drive copy permissions, storage, API quotas, and rclone shared-client availability apply. Imports preserve files already copied when cancelled or interrupted.
